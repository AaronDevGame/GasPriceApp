# DOE fuel adjustments

The existing `GET /fuel-prices` returns retail pump-price estimates. Fuel adjustments are a separate, nationwide DOE notice feed. A negative change means a decrease in PHP per liter; a positive change means an increase. `null` means the notice does not list that product for the company.

`GET /fuel-prices/adjustments?weeks=3` returns company-level adjustments from the latest three imported Tuesday-to-Monday notice weeks. It uses the same guest bearer token and `X-App-Instance-Id` as the other fuel-price read endpoints, or the established browser cookie. `weeks` accepts 1 through 52 and defaults to 3. It only reads PostgreSQL. An empty `items` array means no notices have been imported. The response includes `sourceUrl`, `fetchedAtUtc`, and `effectiveAtUtc`; it is not a current pump-price feed.

`POST /admin/fuel-prices/adjustments/import` requires `Authorization: Bearer <ADMIN_API_KEY>`. With no query parameter, it looks for the first PDF link on DOE's [Price Adjustments page](https://doe.gov.ph/data-and-prices/liquid-fuels/retail-pump-prices/price-adjustments), which DOE currently orders newest first. For a specific historical notice, pass a URL-encoded `sourceUrl` query parameter pointing to a DOE PDF. Only HTTPS links on DOE's approved hosts or its current attachment CDN are accepted. This endpoint takes no request body.

The backend downloads the PDF, sends its bytes to the configured OpenAI model using `agents/philippines-fuel-adjustment-extractor.md`, validates the dates, company names, amounts, and per-company effective times, then inserts or updates matching rows. Its unique key is week start, oil company, and effective UTC time, so importing the same notice again does not add duplicates. A company that stages changes over two dates receives two rows. The importer rejects an empty or structurally invalid extraction without saving rows. Numeric and structural validation cannot guarantee that AI copied every figure correctly; check the source PDF before relying on an imported week. `fetched_at_utc` records the time the successful import saved the rows.

This endpoint is a manual trigger. No recurring scheduler is configured; call it for each new DOE notice until a deployment scheduler is added. The read endpoint never invokes the AI extractor. Set `OPENAI_API_KEY` to enable imports. The PDF itself is not stored in PostgreSQL.
