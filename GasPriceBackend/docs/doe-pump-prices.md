# DOE pump prices

`POST /ai/fuel-prices` still resolves coordinates and checks a fresh research cache first. On a miss it tries DOE city/company pump prices, then the configured direct websites, then AI web search. The DOE source is the regional weekly PDF linked from [Retail Pump Prices](https://doe.gov.ph/data-and-prices/liquid-fuels/retail-pump-prices). DOE rows represent a company price or company price range for a city and fuel grade. They do not identify a physical station.

When DOE supplies the research result, `model` is `direct:doe`, `source_tier` is `government`, and the response includes `doePrices` with the individual company rows. Other research responses have `doePrices: null`. The existing area estimate fields remain available. A DOE import can use OpenAI to read the PDF; the `usage` and `estimatedCost` fields in this response do not include that extraction call.

`GET /fuel-prices/doe?latitude=14.6&longitude=121.0` requires the same player authentication as other fuel-price endpoints. It resolves coordinates, returns the latest fresh rows for the city and province, and attempts a DOE import if none are stored. If DOE has no matching current rows or cannot be read, it returns an empty `prices` array. The endpoint does not return website or AI estimates. A DOE report qualifies until seven days after the report's week end; a current-week report uses its Tuesday start as the estimate date, while a completed report uses its Monday end. The API needs `GEOAPIFY_API_KEY` to resolve coordinates and `OPENAI_API_KEY` for a new PDF extraction.

`POST /admin/fuel-prices/doe/import` accepts JSON `{"city":"Quezon City","province":"Metro Manila","region":"National Capital Region"}` and the admin bearer key. Optional `sourceUrl` selects a DOE PDF explicitly. Without it, the backend finds the newest recent PDF on the matching regional page. The importer extracts only the requested city/province, validates the report week, companies, grades, ranges, and duplicate cells, and upserts matching rows. It returns `imported`, `updated`, or `already_imported`. Admin imports can use older PDFs by supplying `sourceUrl`; the public feed still returns only recent rows.

DOE reports and PDFs can change format. An unreadable or ambiguous extraction is rejected or falls through to the existing sources. Compare imported prices with the linked PDF before relying on them; the PDF extraction is not guaranteed to copy every cell correctly. The import is on demand and may add latency and OpenAI cost on a first lookup for an area.
