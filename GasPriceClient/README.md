# GasPriceClient

This directory is reserved for one Expo/React Native client targeting web, iOS, and Android. The Expo project has not been initialized yet.

The shared app, routes, components, API client, and configuration will live at this directory's root. The `web/` directory is for web-only code or assets. The `ios/` and `android/` directories are reserved for native projects generated by Expo when those builds are needed. They are not separate apps or Git branches.

Native build caches and local signing files are ignored. Before generating native projects, choose whether to commit the generated `ios/` and `android/` source or regenerate it from Expo configuration; the current ignore rules leave either choice open.
